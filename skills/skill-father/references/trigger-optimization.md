# Trigger 优化指南

## Trigger 的目标

Trigger 的目标不是"介绍 Skill"，而是：

**提升 Agent 检索准确率**

让 Agent 在正确的时间激活正确的 Skill。

---

## description 优化

### 必须包含的元素

1. **用户意图**
   - 用户想要达成什么目标
   - 用户的真实需求是什么

2. **同义表达**
   - 同一需求的不同表达方式
   - 常见的变体

3. **典型场景**
   - 典型的使用场景
   - 常见的应用上下文

4. **上下文信号**
   - 触发该 Skill 的关键词
   - 相关的技术术语
   - 领域特定词汇

5. **排除条件**
   - 什么情况下不应该触发
   - 与其他 Skill 的边界

### 好的 description 示例

```yaml
description: |
  从 PDF 文件中提取文本和表格，填写 PDF 表单，合并多个 PDF。
  当用户提到 PDF、表单、文档提取时使用。
  不适用于：图片转 PDF、PDF 转图片、简单的 PDF 阅读任务。
```

### 差的 description 示例

```yaml
description: |
  帮助处理 PDF。
```

## Semantic Trigger 优化

### 触发关键词选择原则

1. **具体性**：选择具体而非泛泛的关键词
2. **多样性**：包含同义词和变体
3. **准确性**：避免与其他 Skill 冲突
4. **覆盖性**：覆盖主要使用场景

### 示例

**好的触发关键词**：
```yaml
semantic:
  - 创建 skill
  - 生成技能
  - 构建 agent 能力
  - workflow 自动化
  - AI 工作流设计
  - 可复用工作流
  - 能力抽象
```

**差的触发关键词**：
```yaml
semantic:
  - 创建
  - 生成
  - 构建
```

## should_trigger_when 优化

### 明确触发条件

列出所有应该触发该 Skill 的情况：

```yaml
should_trigger_when:
  - 用户希望构建可复用 AI 工作流
  - 用户描述重复性任务
  - 用户需要标准化能力模块
  - 用户需要 Agent 自动执行任务
  - 用户需要测试驱动的 AI 能力设计
```

### 触发条件的特点

- **明确**：每个条件都是明确的判断标准
- **完整**：覆盖主要触发场景
- **不重叠**：与其他 Skill 的触发条件不重叠

---

## should_not_trigger_when 优化

### 明确排除条件

列出所有不应该触发该 Skill 的情况：

```yaml
should_not_trigger_when:
  - 一次性简单提问
  - 普通聊天
  - 单次文本生成
  - 不具备复用价值的需求
```

### 排除条件的作用

- 避免误触发
- 明确 Skill 边界
- 提升检索准确率

---

## 检索质量优化

### 1. 提升 Precision（精确率）

减少误触发：
- 优化排除条件
- 增加特定关键词
- 明确上下文信号

### 2. 提升 Recall（召回率）

减少漏触发：
- 增加同义词
- 覆盖更多场景
- 包含变体表达

### 3. 平衡 Precision 和 Recall

根据 Skill 的特性调整：
- 如果误触发代价高，优先提升 Precision
- 如果漏触发代价高，优先提升 Recall

---

## Trigger 评估

### 评估指标

- **触发准确率**：>= 92%
- **误触发率**：<= 5%
- **漏触发率**：<= 8%

### 评估方法

1. 收集真实用户请求
2. 手动标注应该触发的 Skill
3. 运行 Trigger 逻辑
4. 对比结果
5. 计算指标

### 持续优化

根据评估结果：
- 调整 description
- 更新 semantic trigger
- 优化 should_trigger_when
- 优化 should_not_trigger_when

---

## 常见问题

### Q1: 如何避免与其他 Skill 冲突？

A: 明确每个 Skill 的边界，使用排除条件，优化关键词的特异性。

### Q2: 如何处理同义词？

A: 在 semantic trigger 中包含所有主要同义词，在 description 中说明同义表达。

### Q3: 如何平衡精确率和召回率？

A: 根据业务需求调整。如果误触发代价高，优先精确率；如果漏触发代价高，优先召回率。

### Q4: 如何验证 Trigger 的有效性？

A: 使用真实的用户请求数据进行评估，计算触发准确率、误触发率、漏触发率。
